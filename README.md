## ✨ Описание проекта

**TynnPet** — это легкое декоративное приложение, создающее эффект «живого» персонажа на вашем экране. Питомец рендерится с честной прозрачностью без рамок, стандартных окон Windows и панелей управления, что позволяет ему эстетично вписываться в любое оформление рабочего стола.

### Основные фишки:
* **Абсолютная прозрачность:** Никаких фоновых квадратов, только ваш персонаж.
* **Режим «Всегда сверху»:** Питомец не прячется за открытыми браузерами, играми или папками.
* **Умное управление мышью:** Приложение точно отличает быстрый клик (интеракция) от зажатия (перетаскивание).
* **Интерактивные эффекты:** При клике питомец плавно сжимается на долю секунды и может воспроизводить звук.
* **Автономность:** Программа поставляется в виде одного переносимого (portable) `.exe` файла и не требует установки.

## 🎮 Как управлять питомцем

* **Левый клик:** Кликнуть по питомцу (срабатывает анимация нажатия и звук).
* **Зажать и тащить:** Переместить питомца в любое удобное место на экране.
* **Правый клик по иконке в трее (возле часов):** Открывает главное меню управления.

## ⚙️ Меню системного трея и настройки

Управление всеми функциями приложения происходит через аккуратное меню в системном трее Windows:

* **Сделано Tynn** — информационная строка автора.
* **Звук: Вкл/Выкл** — быстрое переключение озвучки при клике.
* **Изменить размер** — открывает окно ввода, где можно вручную задать размер питомца в пикселях (поддерживается диапазон от 50 до 1000). Приложение сохраняет оригинальные пропорции вашей картинки и центрирует её без растягивания.
* **Выбрать питомца / Выбрать звук** — списки для мгновенного переключения между загруженными скинами и аудиофайлами.
* **Импорт питомца (PNG)** — добавление собственного изображения персонажа.
* **Импорт звука (WAV)** — добавление собственного звукового эффекта.
* **Язык** — мгновенное переключение интерфейса между Русским и Английским.
* **Открыть Github** — переход на страницу проекта.
* **Выход** — полное закрытие приложения.

## 📂 Где хранятся файлы и настройки?

При первом запуске `TynnPet.exe` автоматически создает рабочую среду в системной директории пользователя. Если папка пуста, приложение само сгенерирует базового питомца по умолчанию.

Все данные находятся по пути: `%APPDATA%/TynnPet/`

* **`pets/`** — папка, куда сохраняются все импортированные PNG-картинки с прозрачным фоном.
* **`sounds/`** — папка для ваших аудиоэффектов в формате `.wav` (рекомендуется несжатый формат PCM 16-bit).
* **`config.json`** — файл настроек, где приложение запоминает выбранный язык, громкость, размер и координаты питомца, чтобы вам не приходилось настраивать его заново после перезапуска.
